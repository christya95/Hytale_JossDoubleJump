JossDoubleJump — players & quick server setup
==============================================

1. Download JossDoubleJump.jar
   From this repo: open the "dist" folder and download JossDoubleJump.jar
   (On GitHub you can use the "Raw" button on the file for a direct link.)

2. Put the jar in your Hytale SERVER folder:
   <server>/mods/JossDoubleJump.jar

3. Add config folder + file:
   <server>/mods/JossDoubleJump/double_jump_config.json
   Copy from: runtime-config/double_jump_config.json (in this repo)

4. Start the server. Jump, jump again in the air — double jump!

Remove other double-jump mods first so they don't conflict.
