# 📥 Grab the mod here

Want **just the JAR**? You’re in the right neighborhood.

## Option A — Latest from the repo (quick)

The ready-to-run Java file lives at:

**[`../dist/JossDoubleJump.jar`](../dist/JossDoubleJump.jar)**

On GitHub: open **`dist/`** → **`JossDoubleJump.jar`** → download (or use *Raw* for a direct link).

## Option B — GitHub Releases (cleanest for players)

Check this repo’s **Releases** tab on GitHub for tagged builds with attached artifacts (when published).

## Option C — Config to drop next to your server

Copy the sample from **`runtime-config/double_jump_config.json`** into your server folder as:

`mods/JossDoubleJump/double_jump_config.json`

(Same layout as running [`scripts/sync-to-mods.ps1`](../scripts/sync-to-mods.ps1) from a full checkout.)
